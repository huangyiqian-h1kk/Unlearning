# Experiments

The paper-facing experiment index is in
[`paper_runs/`](paper_runs/README.md). It distinguishes:

1. all 25 evidence-backed cells represented in the paper tables; and
2. the five ConRep runs whose original train/evaluation/job files can be
   identified exactly.

Large historical sweeps and superseded launch scripts are retained under
`legacy/`; pinned upstream frameworks are under `third_party/`. Neither is
the recommended starting point for reproducing the paper.
