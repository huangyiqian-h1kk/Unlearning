# Preserved exploratory and superseded code

This directory is provenance, not the paper reproduction interface.

- `llm2vec/` contains exploratory trainers, grid-search generators, and old
  evaluator launchers that were not selected as the five paper run capsules.
- `llm2vec_extensions/` contains project experiments formerly mixed into the
  upstream LLM2Vec tree.
- `open_unlearning_jobs/` contains historical baseline launch scripts. Their
  presence does not establish that a script produced a selected paper cell.

Start from [`experiments/paper_runs/`](../experiments/paper_runs/README.md)
when tracing paper results. Keep these files only for historical investigation.
